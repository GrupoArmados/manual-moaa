# Grupo Armados · Manual de infantería básica

**Abrir el visor en GitHub Pages**  
https://grupoarmados.github.io/manual-moaa/

Para consultar el manual, abre el **enlace completo que te ha compartido la Academia**. Incluye la clave de lectura después de `#` y funciona sin cuenta de GitHub. Si solo tienes la dirección de arriba, solicita el enlace completo a la Academia.

## El libro

Portada e índice, cuatro capítulos (infante básico, orientación, comunicaciones y vehículos ligeros) y un glosario. Puede leerse de principio a fin o consultarse por hojas en móvil y escritorio.

## Este repositorio

- `index.html` abre el visor. El navegador utiliza la clave del enlace para mostrar el libro.
- `manual.bin` contiene la edición cifrada con los capítulos y los recursos visuales.
- `.nojekyll` permite servir la web estática directamente con GitHub Pages.

El equipo mantiene los capítulos HTML por separado en el repositorio privado de edición. Las actualizaciones de lectura se distribuyen aquí con la misma dirección.
